# Commander SeruP — Progress Tracker v1

Open `index.html` with VS Code Live Server.

### Publish
Edit `data.js`, especially `history` and the subject `done` counts, then:
`git add .`
`git commit -m "update progress"`
`git push`

The academic day automatically rolls over at **04:00 IST**. Browser checkboxes are saved locally for preview; public updates require editing `data.js` and pushing to GitHub.

## Best Friend section
Edit `bestFriend.name`, `bestFriend.role`, and `bestFriend.message` in `data.js` to personalize the gratitude section.
